## 🛠️ How to Compile

### Option 1: Compiling Online (Overleaf / ShareLaTeX)
1. Log in to [Overleaf](https://www.overleaf.com/).
2. Create a **New Project** -> **Blank Project**.
3. Upload Python_Lab_Manual.tex.
4. Set the compiler to **pdfLaTeX** (or XeLaTeX / LuaLaTeX).
5. Click **Recompile**.

### Option 2: Compiling Locally (MiKTeX / TeX Live + VS Code / TeXstudio)
Run the following command in your terminal:

`ash
pdflatex Python_Lab_Manual.tex
pdflatex Python_Lab_Manual.tex
`
